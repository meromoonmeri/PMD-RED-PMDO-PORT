# Map Database (PMD Red Extraction)

Ce document liste l'intégralité des 245 cartes présentes dans le code de Pokémon Donjon Mystère : Équipe de Secours Rouge.

*(Extrait généré via l'outil `extract_pmd_red.py`)*

## Arcs Scénaristiques (Story Maps)
### 1. Villes et Hubs
- `T01P01` : Place Pokémon
- `T01P02A` / `T01P02B` : Étang Barbicha
- `T01P03` / `T01P04` : Poste Bekipan (Extérieur / Intérieur)
- `T01P05` / `T01P06` : Dojo Makuhita (Extérieur / Intérieur)
- `T00P01` : Base de l'Équipe de Secours (Extérieur par défaut)

### 2. Arc Fugitifs (Fugitive Arc)
- `D08P01` / `D08P02` : Grotte Lapis (Entrée / Fond)
- `D09P01` / `D09P02` / `D09P03` : Mont Brasier (Entrée / Relais / Sommet de Sulfura)
- `D10P01` / `D10P02` / `D10P03` : Forêt Givrée (Entrée / Relais / Arène Artikodin)
- `D11P01` / `D11P02` / `D11P03` : Mont Gel (Entrée / Relais / Autel Feunard)

### 3. Le Climax (La Météorite)
- `D12P01` à `D12P04` : Caverne Magma (Entrée -> Fosse de Groudon)
- `D13P01` à `D13P03` : Tour Céleste (Entrée -> Sommet de Rayquaza)
